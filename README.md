## About me

I'm a French developer focused on the **Minecraft: Bedrock Edition** server ecosystem.

I mainly build plugins, developer tools and server-side systems using:

- **Java** with PowerNukkitX
- **PHP** with PocketMine-MP
- **Python** for tooling and Linux projects

I care about performance, maintainable architecture and simple developer experiences.
